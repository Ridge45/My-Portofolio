# Ridge Portfolio (React)

Free modern portfolio — Vite + React + Tailwind + Framer Motion + Three.js.

## Local

```bash
cd web
npm install --legacy-peer-deps
npm run dev
```

Open http://localhost:5173

## Free deploy on Vercel ($0)

1. Push the `web` folder (or whole repo) to GitHub
2. Go to [vercel.com](https://vercel.com) → Import project
3. Set **Root Directory** to `web`
4. Deploy — you get `https://your-project.vercel.app` free

No domain purchase required.

## Stack

| Need | Used |
|------|------|
| Framework | Vite + React + TypeScript |
| Animations | Framer Motion |
| 3D | Three.js + React Three Fiber |
| Icons | Lucide |
| Styling | Tailwind CSS v4 |
| Themes | Dark / light toggle |
| Hosting | Vercel (free subdomain) |
